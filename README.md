\# 🏋️‍♂️ GymLink \*\*GymLink\*\* es una plataforma web integral de gestión y fidelización para gimnasios. Combina la administración de usuarios y la asignación de rutinas personalizadas con un motor de gamificación basado en control de asistencia (\*check-ins\*), acumulación de rachas y un catálogo de recompensas canjeables para convertir el entrenamiento diario en una experiencia motivadora. --- ## 🎯 Product Goal &gt; \*\*Aumentar la rentabilidad y retención en los gimnasios motivando la asistencia constante de los socios a través de un sistema dinámico de check-ins, rachas y recompensas canjeables.\*\* ## 🚀 Objetivo del Sprint 1 (Sprint Goal) &gt; \*\*Construir la base del sistema y maquetar la interfaz principal de GymLink, habilitando la autenticación segura por roles (Socio/Admin/) y las vistas clave para el control de asistencia y puntos.\*\*
